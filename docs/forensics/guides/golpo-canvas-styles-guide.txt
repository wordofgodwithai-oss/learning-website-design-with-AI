Get Started Every Visual Style Available on Golpo Canvas (2026 Guide)
See all 11 named Golpo Canvas styles: ten with Compact and Expanded profiles, plus the Compact-only Notebook style and playable Pen, Marker, and Stylus in Hand examples.
Daniel Rivera • March 10, 2026 • 4 min read 

Golpo Canvas now includes 11 named visual styles . Ten established style families offer both Compact and Expanded profiles. Compact combines more components within each scene so viewers can see more of the explanation together and retain the relationships between its ideas. Expanded distributes those components across more scenes, giving each component more visual space and revealing the explanation in smaller steps. The earlier, original profiles are now named Expanded. Notebook is the newest style and is Compact-only.

Matched examples throughout: this page now uses the same ten Compact/Expanded pairs as the dedicated comparison guide . Each pair keeps the subject fixed so you can compare the profiles directly.

Compact and Expanded profiles

Compact: combines more components within each scene to retain the explanation and the relationships between its ideas.
Expanded: distributes those components across more scenes, giving each component more visual space and revealing the explanation in smaller steps. It is the public name for the earlier, original profile.
Notebook: Compact-only.

Compact/Expanded is separate from the visual style itself, and separate from duration and Horizontal/Vertical orientation. For REST integrations, see the official API documentation : unsuffixed v1 image_style and v2 canvas_style_variant values select Compact; the ten pre-Notebook styles accept _legacy for Expanded; Notebook uses notebook_infographic .

Pen-in-Hand animation options

Pen-in-Hand controls how the Canvas artwork is revealed. It is separate from the visual style and from the Compact or Expanded profile: choose the Canvas style and profile first, then choose Pen, Marker, or Stylus for the drawing-tool effect.

Which style should you pick?

Classroom and concept explanations: either Chalkboard treatment, Whiteboard, or Notebook.
Product, business, and finance: Modern Minimal, Editorial, or Technical.
Friendly storytelling: Playful or Illustration.
Direct marker energy: Sharpie.

Use the examples as a shortlist, then generate a short test with your own script. Keep the script, voice, pacing, and orientation fixed when comparing two profiles.
