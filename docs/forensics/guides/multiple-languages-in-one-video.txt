Features & Editing How to Create a Video With Multiple Languages in Golpo
Watch one video combine English, German, French, and Hindi, then try English–Spanish and English–Bengali lessons. Copy the exact Script Only scripts and saved settings behind all three.
Maya Okonkwo • October 21, 2026 • 13 min read 

You can create one video with multiple spoken languages by writing those languages directly into a Script Only script in Golpo. This guide shows three finished examples: English with German, French, and Hindi in a single 46.50-second video; an English–Spanish lesson; and an English–Bengali lesson. Each teaches “What’s your name?”, “How old are you?”, and “Where do you live?”

The useful detail: all three examples had Language set to English . The script itself supplies the language switches. Watch the videos below, then copy their exact scripts and saved settings.

How to create your own video with multiple languages

Choose the phrases and write the translations first. Decide what the learner should hear. For a phrase lesson, write each source question followed immediately by its translation. Use a fluent reviewer to check meaning, spelling, and the level of formality before generation.

Open Golpo and choose Script Only mode. Paste the complete narration into the Script field. The script should contain the actual words in every language, rather than a request such as “make this bilingual.” See the Prompt Mode vs Script Mode guide for the input-mode controls.

Make the transitions part of the narration. Start with “We’ll learn some English to Spanish translations.” For another section, add a spoken transition such as “Now we’ll learn some English to French translations.” Put a blank line between language sections so you can review the structure easily.

Start with the demonstrated settings. To reproduce these examples, use Canvas, Female 1, English for Language, and English for Display Language. Choose a duration suitable for the complete script and check the character allowance shown in your current interface. Keep native characters, accents, and punctuation.

Choose how the video should look. Try Chalkboard Color, Editorial Compact, or Notebook Infographic. All three examples used Fast pacing, Auto visual animation, no background music, and Generate on-screen text using only the script content enabled. The Canvas styles guide helps you choose the layout.

Review the script and create the video. Read every source-and-translation pair aloud before submitting. If you use the separate Edit script before creating video control, approve that script before rendering. The examples above were generated directly with that review control off.

Watch and listen through every language switch. Check pronunciation, omitted words, pacing, visible characters, and the exported length. Ask someone fluent in each target language to review the result before teaching from it or sending it to customers.

How to write the script so the language switches are clear

Write a spoken relationship between the two phrases. “What’s your name?” followed by “is translated as” and the target-language question gives the narration a clear order. A list of language names or an instruction to translate does not supply the words you want spoken.

Use one language pair per short section. The first example repeats the same three English questions in German, French, and Hindi sections. That repetition lets the viewer compare translations without learning a new question at every switch. Add a spoken transition when the target language changes.

Keep the original writing system. The Hindi phrases use Devanagari, and the Bengali phrases use Bengali script. Preserve characters such as ß, ¿, ñ, and accented French letters. If you need transliteration for your audience, decide whether it belongs in the spoken lesson or in the visual directions before you add it.

Keep production directions in their own fields. Putting “switch to Hindi now” or “[show the translation]” into Script Only mode may turn those words into narration. Write a natural spoken transition in Script, and place visual directions in Video Instructions.

Spoken language and on-screen text need separate checks

The Script supplies the multilingual narration. Display Language is a separate setting for visible wording. In these examples it stayed on English, while the scripts supplied the German, French, Hindi, Spanish, and Bengali phrases visible in the finished videos.

Generate on-screen text using only the script content was enabled in all three. That setting limits the source wording available for generated labels; it does not make every word appear on screen, set the spoken language, or replace proofreading. See the on-screen text from script guide for a fuller explanation.

Check the final video against the supplied script. Generated display text can still need a correction: for example, the Bengali video shows “What’s your nme?” where the supplied English script says “What’s your name?” The original video is embedded here unchanged so you can judge the output yourself.

What to check if your multilingual video needs a correction

A phrase is missing or changed: confirm that Script Only mode is enabled and that the exact phrase is present in Script. A topic prompt and a complete narration serve different purposes.

A language switch sounds rushed: use shorter phrases and clearer sentence breaks, then review the new render. For a lesson with distinct language sections, the sentence-to-scene selection guide explains how to plan scene boundaries.

The pronunciation needs work: have a fluent reviewer identify the exact phrase. Revise that phrase or test voice delivery on a short passage before creating a longer lesson. The same voice may not perform equally across every language or accent.

The visible translation differs from the spoken one: compare both with the approved script and review the display-text setting. A correct script still needs a visual check of accents, spelling, and non-Latin characters.

You need a separate video for each language: use the multilingual video editions workflow . That serves a different goal from mixing languages inside one continuous video.

Frequently asked questions
Can Golpo speak multiple languages in the same video?
Yes. The examples on this page use one Script Only narration containing several languages. The first video combines English with German, French, and Hindi; the other two pair English with Spanish and Bengali.
Do I need to select every language in the language picker?
To reproduce these examples, leave Language set to English and paste the mixed-language narration into Script Only mode. All three saved examples used English for both language and display_language. Selecting several output languages is a separate workflow for creating localized video editions.
Should I write the foreign-language phrases or ask Golpo to translate them?
For this Script Only workflow, write the actual phrases in every language before generation. Put each source phrase beside its translation, keep native characters and accents, and review the wording with someone who knows the language.
What is the difference between Script, Video Instructions, and Voice Instructions?
Script contains the words to speak. Video Instructions describe what to draw and which labels to show. Voice Instructions describe delivery, pace, and tone. All three published examples left Video Instructions and Voice Instructions empty.
Does the script-only on-screen text setting control the spoken language?
No. Generate on-screen text using only the script content restricts the wording available for generated display text. The mixed-language Script supplies the narration. The checkbox was enabled in all three examples, and it does not guarantee that every script word appears on screen.
Can I keep Hindi or Bengali in its native script?
Yes. The supplied Hindi example uses Devanagari and the Bengali example uses Bengali characters. Keep those characters in your script and review both the generated narration and any visible text before sharing.
Which voice and visual styles were used?
All three examples used Female 1, saved as solo-female-3, with fast pacing and Auto visual animation. Their Canvas styles were Chalkboard Color (neon), Editorial Compact (editorial_compact), and Notebook Infographic (notebook_infographic).
Why is the finished video longer or shorter than the duration selected?
Treat the duration selection and exported runtime as separate values. The 1-minute example exports at 46.50 seconds; the two examples saved with 0.25-minute selections export at 18.93 and 20.43 seconds. Check the finished file rather than assuming the selection is its exact runtime.
Will every language and accent sound equally natural?
These three videos demonstrate these particular scripts and one selected voice. They do not establish equal pronunciation quality for every language, accent, or voice. Listen to every language switch and ask a fluent reviewer to check pronunciation, meaning, and register before using the video for teaching or customers.
