Features & Editing Golpo Canvas Compact vs Expanded: Every Style Compared + Notebook
Compare all ten Golpo Canvas styles in Compact and Expanded profiles using matched video pairs, then watch the new Compact-only Notebook style.
Sophie Müller • September 3, 2026 • 9 min read 

Golpo Canvas now gives each of its ten established visual-style families two clearly named choices: Compact and Expanded . The earlier, original Canvas profiles have not disappeared; they are now named Expanded. Compact is the newer option.

Also new: Notebook. Notebook is an additional Golpo Canvas style built for a notebook-like visual treatment. It is Compact-only, so there is no Expanded Notebook comparison to show. 
This guide uses the same subject inside each pair. That makes the comparison useful: you are judging the Compact and Expanded profiles rather than two unrelated scripts.

What the names mean

Compact combines more components within each scene so viewers can see more of the explanation together and retain the relationships between its ideas.

Expanded distributes those components across more scenes, giving each component more visual space and revealing the explanation in smaller steps. It is the new public name for the earlier, original profile of each established Canvas style.

Notebook is an additional Compact-only style.

Compact/Expanded is separate from orientation and duration. Continue to choose Horizontal or Vertical and the video duration independently.

In the Golpo creator, choose Golpo Canvas , select the visual style, and use the available Compact or Expanded choice for that style. If you are integrating through REST, the official Golpo API documentation says unsuffixed image_style (v1) and canvas_style_variant (v2) values select Compact. Add _legacy to one of the ten pre-Notebook values for Expanded. Notebook uses notebook_infographic and has no _legacy form.

Frequently asked questions

What is the difference between Compact and Expanded in Golpo Canvas?
Compact combines more components within each scene so viewers can see more of the explanation together and retain the relationships between its ideas. Expanded distributes those components across more scenes, giving each component more visual space and revealing the explanation in smaller steps. The earlier, original profile is now called Expanded, while Compact is the current default when an unsuffixed REST API style value is used.

Were the older Golpo Canvas styles removed?
No. The earlier Canvas profiles remain available and are now named Expanded. Compact is available alongside Expanded for the ten pre-Notebook style families.

Does the Notebook style have Compact and Expanded versions?
Notebook is Compact-only. It does not have an Expanded counterpart or a REST API _legacy alias.

Golpo Canvas — Compact vs Expanded
The same topic rendered in both style profiles for every Canvas family the API exposes. Compact ( _compact suffix) packs more content into each scene; Expanded (unsuffixed value, the default) spreads content across more scenes. Notebook is Compact-only. Each tile's payload sends the exact canvas_style_variant shown — see Canvas Style for the full value table.

Are the comparison videos fair pairs?
Yes. Each Compact and Expanded pair uses the same subject so you can compare the style profile without changing the topic.
