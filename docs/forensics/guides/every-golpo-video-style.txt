Golpo Sketch styles

The original Golpo pipeline. Hand-drawn-feeling whiteboard animation rendered through Golpo's line-art engine. Pick a built-in Sketch style under the Style dropdown, or choose + Custom Style to follow an image, video, or written description.

One thing to know about pace: all the Sketch videos below were generated with the default Pace setting of Fast — a tighter, quicker-feeling animation that matches what you get out of the create-video screen by default. Switch Pace to Normal in the dashboard (or set the equivalent field in the API payload) if you want slower, more deliberate pacing.

Golpo Canvas styles

Golpo Canvas is the image-generation-driven pipeline. Ten established visual-style families offer both Compact and Expanded profiles. The examples below use the same matched pairs as the Compact vs Expanded guide .

How to compare the pairs: Expanded distributes components across more scenes for additional visual space and smaller explanatory steps. Compact combines more components within each scene so viewers can see more of the explanation together. Each pair below uses the same subject in both profiles. Notebook is Compact-only.

Golpo Canvas Pen-in-Hand animation styles

Canvas also lets you choose how the artwork appears. Pen-in-Hand animation places a realistic hand and drawing tool on screen as each illustration is revealed, giving any Canvas visual style a more handcrafted whiteboard feel. Choose the visual style first, then pair it with one of these three animation options.

Pen in Hand

A fine-tipped pen draws precise, elegant lines. Pick it for clean professional explainers, detailed diagrams, and restrained visual styles. Watch How to be a good person :

Marker in Hand

A bold marker produces thicker, more confident strokes. Use it when you want the energy of a live whiteboard session and stronger visual punch. Watch Secret for success of a startup :

Stylus in Hand

A digital stylus draws on a tablet-like surface. It feels modern and tech-forward, making it a natural match for SaaS, product, engineering, and digital-native content. Watch How to Ace an Exam? :

Compatibility and access: Pen-in-Hand works with all Canvas visual styles. Pen, Stylus, and Marker are available on the Scale plan and above.

Picking a style

Watch the videos above and pick the one whose look matches the audience and tone you're targeting. There's no wrong answer — generate a quick 30-second test in two or three candidate styles and compare side by side before committing to a longer video.

If none of the visible styles fit, try the three remaining Sketch styles from the same dropdown, or create a Custom Style from an image, video, or description. For Canvas, compare Compact and Expanded where both are offered, then compare the default reveal against Pen, Stylus, and Marker animation before committing to a longer video.
