What is Custom Style?

Custom Style is a reusable style definition for your Golpo videos, available in both Golpo Canvas and Golpo Sketch. Instead of choosing only from built-in looks—Chalkboard, Editorial, Technical, or Illustration on Canvas, or Classic, Infographics, and the rest on Sketch—you can create a new style from one of three inputs:

Plan availability: Custom Style is available starting with the Business plan and is included on higher subscription tiers. See the full Golpo pricing breakdown for a plan-by-plan comparison.

An image whose colors, drawing language, texture, typography, or composition you want the animation to evoke

A video whose overall art direction and visual treatment you want to use as inspiration

A description that tells Golpo the medium, palette, lighting, mood, setting, and other visual qualities you want

Once saved, the style appears under My Styles . You can select it for the current video or return to it later, which is useful when a series of videos should feel visually related.

The same reference will not produce identical results in both engines. Canvas interprets a reference as a full illustrated scene; Sketch interprets it through its hand-drawn line-art pipeline. The Ganesha example above is the clearest case—a pure line-art reference suits Sketch naturally, while a richly shaded painting usually has more to give Canvas.

How to create a Custom Style, step by step

Step 1: Select your video engine

Start a new video as usual: enter your prompt or script and add any source material you need. Then select Golpo Canvas or Golpo Sketch as the video engine. Custom Style is available in both. The screenshots below show the Canvas flow; the steps are the same in Sketch.

Select Golpo Canvas before choosing the visual style. 

Step 2: Open the Style menu

Scroll to the video configuration controls. Locate Style beside the other settings, then open the dropdown. This is the same dropdown you would use to pick a built-in style in either engine.

Open the Style dropdown in the Canvas configuration area. 

Step 3: Choose + Custom Style

The menu shows Golpo's preset styles for the engine you selected first. Select + Custom Style . Any styles you have already created appear beneath it in the My Styles section.

Choose + Custom Style. Saved styles remain available under My Styles. 

Step 4: Name the style and add its inspiration

The Add Custom Style modal opens. Give the style a clear name—up to 60 characters—so you can recognize it later. Then choose how to create it:

Image or Video: click the upload area or drag in a reference file. The modal accepts an image or video up to 10 MB.

Description: switch to the Description tab and write the art direction you want Golpo Canvas to follow.

Name the style, choose Image or Video or Description, add the reference, and select Add Style. 

A useful naming pattern: describe the visual system, not the current topic. Names such as “Neon Chalk on Black,” “Greek Pottery Parchment,” or “Soft Editorial Watercolor” will still make sense when you reuse the style months later.

Step 5: Add and select the saved style

Select Add Style . The new style is saved to My Styles and becomes available in the Style dropdown. Select it for the current video, finish the other video settings, and generate.

You do not have to rebuild the style the next time you need it. Return to the Style menu and choose it from My Styles.

Step 6: Review what influenced a finished video

After the video is created, open it in Library and view its configuration. Golpo keeps the provenance visible: you can see the image, video, or written description that influenced the animation. That makes it easier to audit a result, understand why it looks the way it does, and recreate a consistent series later.

Should you use an image, video, or description?

Use an image when one visual says it all

An image is the fastest choice when you have a strong, representative example: a brand illustration, a poster, a classroom drawing, a texture study, or a frame whose palette and line work already capture the look you want.

Choose an image that contains the qualities you want repeated across scenes. A clean reference with an intentional palette and recognizable drawing language is usually more useful than a busy collage of unrelated ideas.

Use a video when motion has a visual language

A video reference is useful when the overall treatment develops over time—perhaps the palette, borders, transitions, recurring motifs, or composition style are clearer across several frames than in one still image. The Lila's Story example above came from a reference whose palette and character styling were consistent across the whole clip.

The reference does not need to cover the same topic as the new video. It needs to communicate the visual world you want the new Canvas animation to inhabit.

Use a description when you can articulate the art direction

A description gives you precise control without finding a reference asset. It is also the only option that lets you set different rules for different subjects, the way the Love Triangle example asks for stick figures for people and solid-color realism for everything else. The strongest descriptions usually combine several concrete visual dimensions:

Medium: ink illustration, cut paper, watercolor, cel animation, chalk, collage

Surface or texture: weathered parchment, grainy film, clean vector shapes, rough paper

Palette: muted earth tones, neon cyan and magenta, gold and deep blue

Lighting: dramatic side light, soft daylight, high-contrast stage lighting

Composition: cinematic landscapes, centered diagrams, magazine-like layouts

Mood: epic, playful, calm, mysterious, technical, archival

A practical template is:

Use a [medium] style inspired by [visual references or era]. Combine [character or object treatment], [background or transition treatment], and [palette or lighting] to create a [mood] feeling. 

Tips for better Custom Styles

Use one coherent visual reference. A focused image, clip, or description gives the style a clearer direction than several conflicting aesthetics.

Name for reuse. “Black-and-Gold Greek Pottery” is easier to find later than “History Video Style.”

Describe visible qualities. Words such as “beautiful” or “professional” are subjective. Medium, palette, texture, lighting, and composition give Golpo something concrete to work with.

Match the reference to the job. A single image is ideal for a stable graphic language; a video is useful when the treatment unfolds across frames; a description is best when you already know the art direction you want.

Check Library before a sequel. Review the saved inspiration and configuration from an earlier video before generating the next installment in a series.

Match the reference to the engine. Line art, ink drawings, and flat graphic references translate well into Golpo Sketch. Painted, textured, or fully rendered references usually have more for Golpo Canvas to work with.

Use references you are allowed to use. Upload your own material or content you have permission to use as visual inspiration.

Build a visual library, not just one video

The most powerful part of Custom Style is persistence. A style is not trapped inside one generation. Save a strong visual direction once, give it a memorable name, and it becomes part of your Canvas toolkit.

That opens up repeatable looks for course modules, episodic stories, customer-education series, campaigns, internal training, and branded explainers—while keeping the original inspiration visible in Library for future reference.
