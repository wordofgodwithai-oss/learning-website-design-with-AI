Golpo Python SDK

v2.0 - Latest Python 3.8+ 
The Golpo Python SDK helps you create whiteboard animation explainer videos and podcasts from text prompts and documents. Features include uploading any document, choosing timing, voice instructions, background music, and more.
What's new in v2.0
New generation flow: create_video and create_podcast first create a job and return video_id with status. Then use get_video_status with that video_id to check progress and get the final result.
language_variants and variant_visuals_mode to generate multi-language versions in one request.
own_narration_video_layout , own_narration_video_position , own_narration_split_size , own_narration_video_fit , and own_narration_focus_position for advanced own-narration video placement.
visual_animation_style and onscreen_text_from_script_only for tighter animation and on-screen text control.

Installation

Terminal Copy 
pip install golpo==2.0.0 

Quick Start
Create a client and submit a job.

quickstart.py Copy 
from golpo import Golpo

golpo_client = Golpo(api_key="your-api-key")

job = golpo_client.create_video(
prompt="Explain supply and demand",
style="solo-female-3",
timing="1",
)
print(job.video_id)
print(job.status) 

v1 to v2 Migration
What changed in v2 and how to update your v1 integration.

NOTE: In v1, create_video flow works like a direct final output flow (URL/script returned in the same step). In v2, create_video now works as a job submission step and returns video_id + status first. After that, call get_video_status using the returned video_id to track progress and fetch final URL/script when completed. 
Migration Example
migration_create_video_flow.py Copy 
import time
from golpo import Golpo

client = Golpo(api_key="your-api-key")

# v1-style expectation (older docs)
# result = client.create_video(prompt="Explain gravity")
# print(result.url)
# print(result.script)

# v2.0 flow: submit job first
job = client.create_video(prompt="Explain gravity")
print(f"Submitted job: {job.video_id} ({job.status})")

# then poll status until terminal state
while True:
status = client.get_video_status(job.video_id)
print(f"Current status: {status.status}")

if status.status == "completed":
print(f"Video URL: {status.url}")
print(f"Script: {status.script}")
break

if status.status == "failed":
raise RuntimeError(status.error or "Video generation failed")

time.sleep(2)

Describes how the video should look - visuals, style, and scene direction. Example: "Use clean corporate visuals with data charts." 

use_color bool True Optional If you want a colored video, set this to True.

logo_placement Optional[str] None Optional Where the logo should appear on screen. Accepted values: "tl" (top-left), "tr" (top-right), "bl" (bottom-left), "br" (bottom-right).

use_lineart_2_style Optional[str] None Optional Choose a Golpo Sketch style variant.
NOTE: Do not combine with use_2_style (Golpo Canvas). Use one or the other. 

audio_clip Optional[str | Path] None Optional Your own narration audio/video file or URL.

is_public Optional[bool] None Optional If True, video will appear on Golpo gallery. If False, then it will be private.

use_as_is Optional[str | List[bool]] None Optional Per-frame flags to use generated images as-is without animation. Pass as JSON array string or Python list.
One boolean per frame. Example: [True, False, True] - frames 0 and 2 will use images as-is. 

skip_animation Optional[str | List[bool]] None Optional Per-frame flags to skip the drawing animation. Pass as JSON array string or Python list.
One boolean per frame. Example: [False, True, False] - frame 1 will skip animation. 

user_images Optional[str | Path | List[str | Path]] None Optional User-provided images (file paths or URLs). Local files are auto-uploaded to S3.

user_images_descriptions Optional[str | List[str]] None Optional Descriptions for each user image. Strongly recommended for best visual results.
NOTE: Provide one description per image for best results. Descriptions help the AI understand and position images correctly. 

user_videos Optional[str | Path | List[str | Path]] None Optional User-provided video clips (file paths or URLs). Local files are auto-uploaded to S3.

user_videos_description Optional[str | List[str]] None Optional Descriptions for each user video.
NOTE: Provide one description per video for best results. 

user_audio_in_video Optional[str | List[int]] None Optional List of video numbers that should use AI-generated narration audio instead of their original audio (e.g., [1, 3] means videos 1 and 3 get AI narration; unlisted user videos keep their original audio).
NOTE: Only applies when user_videos is provided. If omitted or empty, all user videos retain their original audio. 

use_2_style bool False Optional Enable Golpo Canvas visual style.
NOTE: Do not combine with use_lineart_2_style (Golpo Sketch). Use one or the other. 

image_style Optional[str] None Optional Canvas style machine name. Bare style names select Expanded; append "_compact" for Compact. "notebook_infographic" is Compact-only.
NOTE: Only available when Golpo Canvas is enabled (use_2_style=True). 

input_images Optional[str | Path | List[str | Path]] None Optional Reference input images for Golpo Canvas. The video will be generated around the provided images.
NOTE: Only available when Golpo Canvas is enabled (use_2_style=True). 

pen_style Optional[str] None Optional Drawing pen style: "stylus", "marker", or "pen".
NOTE: Only available when Golpo Canvas is enabled (use_2_style=True). 

show_pencil_cursor bool False Optional Show a pencil cursor during drawing animation.
NOTE: Only available when Golpo Canvas is enabled (use_2_style=True). 

pacing str "normal" Optional "normal" (15s max per frame) or "fast" (10s max per frame).

display_language Optional[str] None Optional Language for on-screen text in the video (e.g., 'English', 'Hindi', 'French'). Useful when the displayed text should differ from the narration language. Defaults to the value of language if omitted.
Example: language: "Hindi", display_language: "English" — the narrator speaks in Hindi while all on-screen text, titles, and labels are shown in English. 

onscreen_text_from_script_only bool False Optional Controls whether on-screen text is restricted to script content only.
If True, Golpo uses only words from the script/transcript for on-screen text. If False (default), Golpo can also add helpful labels/titles where needed. 

visual_animation_style Optional[str] None Optional Overall animation style preset. Accepted values: "auto", "fade_in", "sketch". Meaning: "auto" keeps Golpo default animation behavior, "fade_in" uses fade-in animation, and "sketch" uses sketch-style animation for generated visual components.
NOTE: Only supported with Golpo Canvas. 

language_variants Optional[List[str]] None Optional Create extra versions of the same video in other languages.
Example: language="English", language_variants=["Spanish", "French"] creates additional Spanish and French versions from the same request. 

variant_visuals_mode Optional[str] None Optional Control whether language variants share visuals or use separate visuals. Accepted values: "shared", "per_language".
shared: all language variants reuse the same visuals from the primary video. Example: variant_visuals_mode="shared". 
NOTE: per_language: each language variant gets its own language-specific visuals. Example: variant_visuals_mode="per_language". 

own_narration_video_layout Optional[str] None Optional Layout for own narration mode. Accepted values: "round_overlay", "side_by_side".
Use "round_overlay" to show a small circular narrator overlay, or "side_by_side" to split screen between narration and visuals. 

own_narration_video_position Optional[str] None Optional Screen position for own narration overlay. Accepted values: "left-top", "right-top", "left-bottom", "right-bottom".
NOTE: This is used for overlay positioning and is most relevant with round_overlay mode. 

own_narration_split_size Optional[str] None Optional How much screen space own narration gets in side-by-side mode. Accepted values: "25%", "30%", "35%", "40%", "50%".
NOTE: Only supported when own_narration_video_layout is side_by_side. 

own_narration_video_fit Optional[str] None Optional Fit behavior for own narration video area. Accepted values: "crop", "full".
NOTE: Only supported when own_narration_video_layout is side_by_side. 

own_narration_focus_position Optional[float] None Optional Focus point (0-100) for cropped own narration video.
NOTE: Only supported when own_narration_video_layout is side_by_side. Use values between 0 and 100.

result = golpo_client.create_video(prompt="Explain AI in 2 minutes")

example_edit_video.py Copy 
video_result = golpo_client.create_video(prompt="Product demo in 3 scenes")
